EPS Escolar — prototipo de demostración
Publicación básica con GitHub Pages:

1. Crea un repositorio nuevo en GitHub (por ejemplo: eps-escolar).
2. Sube el archivo index.html a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), y guarda.
5. Espera a que termine la publicación y abre la URL que GitHub Pages muestre.

Este prototipo usa datos ficticios y almacenamiento local del navegador. No lo uses para matrículas, calificaciones ni información personal real.
